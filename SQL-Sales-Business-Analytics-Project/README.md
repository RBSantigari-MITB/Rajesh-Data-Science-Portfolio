# SQL Sales & Business Analytics Project

This project analyzes sales, customers, products, employees, shipping, freight costs, and order trends using SQL on the Northwind database.

## Tools Used
- MySQL
- Excel
- SQL Joins
- Aggregate Functions
- CASE Statements
- Business KPI Analysis

## Key Analysis Areas
- Product revenue analysis
- Category-wise revenue analysis
- Customer purchasing behavior
- Seasonal sales trends
- Order status analysis
- Employee contribution
- City and country revenue analysis
- Shipper performance analysis
- Freight cost analysis

## Files Included
- `SQL_Business_Analytics_Queries.sql` - contains all SQL queries
- `SQL_Sales_Business_Analytics_Report.docx` - contains results, screenshots, insights, and strategies

## Dataset Note
The analysis was performed on the Northwind database. The dataset is not included in this repository.
